# ADO 3 - Colisões Elásticas 1D

Projeto desenvolvido para a disciplina de Física:
Práticas Extensivas.

## Sobre o projeto

O programa simula colisões elásticas unidimensionais
entre dois blocos, utilizando fórmulas fechadas para
calcular as velocidades finais, o momento linear,
a energia cinética, os impulsos e a força média.

## Funcionalidades

- Animação interativa das colisões.
- Controles para alterar massas e velocidades.
- Comparação dos resultados antes e depois do choque.
- Gráficos de momento linear e energia cinética.
- Simulação dos três casos propostos na atividade.

## Tecnologias utilizadas

- Python
- NumPy
- Matplotlib

## Como executar

Instale as bibliotecas necessárias:

pip install numpy matplotlib

Execute o arquivo:

python ado3_colisoes_elasticas.py
